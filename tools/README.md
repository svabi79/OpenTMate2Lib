# Tools

This directory is reserved for future OpenTMate2Lib tooling.

Possible future tools:

- A pcapng report extractor dedicated to the TMate 2.
- A segment-map generator from the reference segment constants.
- A Linux `hidraw` smoke test.
- A Windows HID smoke test.

Contributions welcome — see the repository [`docs/`](../docs) for the
protocol notes these tools would build on.
